# 결석신고서 만들기

나이스(NEIS)에서 내려받은 **출결 엑셀**을 읽어 학교 **결석신고서 양식(.xlsx)** 을 자동으로 채워 주는 웹페이지입니다.
설치 없이 브라우저(크롬·엣지)에서 바로 쓰며, **파일은 서버로 전송되지 않고 내 PC 브라우저 안에서만 처리**됩니다.

## 주요 기능

- **사유 고르기** — 출결 파일에 있는 사유(생결, 질병, 공결 등)를 건수와 함께 보여 주고, 고른 사유만 양식에 넣습니다.
- **비고란 확인** — 출결 파일 비고란 내용을 한눈에 보여 주고, 학생마다 드롭다운으로 비고를 고르거나 직접 입력합니다.
- **확인 절차** — 학생별 ‘확인’ 체크와 진행 상황 표시. 확인하지 않은 학생이 있으면 내려받기 전에 한 번 더 묻습니다.
- **자동 표시** — 출결구분에 따라 결석(○)·지각·조퇴·결과 칸과 교시를 채우고, 제목의 연·월과 시트 이름(예: `9월`)을 바꿉니다.
- **기억 기능** — 양식 파일, 학생별 확인방법, 고른 사유를 이 브라우저에 기억합니다.

## 사용 방법

1. `index.html`을 엽니다. (또는 아래 GitHub Pages 주소로 접속)
2. **결석신고서 양식(.xlsx)** 을 올립니다. 한 번 올리면 다음부터는 자동으로 불러옵니다.
3. 나이스에서 받은 **출결 엑셀(.xlsx)** 을 올립니다.
4. 넣을 **사유**를 고르고, 학생별 **비고**와 **확인방법**을 확인한 뒤 ‘확인’에 체크합니다.
5. **결석신고서 엑셀 내려받기**를 누릅니다.

처음 써 볼 때는 `examples/` 폴더의 예시 파일(가짜 데이터)로 연습할 수 있습니다.

### 파일 형식 조건

| 파일 | 필요한 머리글 | 있으면 쓰는 머리글 |
|---|---|---|
| 결석신고서 양식 | 번호, 이름(성명), 날짜, 결석, 지각, 조퇴, 결과, 확인방법 | 비고, 사유 |
| 출결 엑셀 | 일자(날짜), 성명(이름), 출결구분, 사유 | 번호, 결시교시, 비고 |

- `.xls` 파일은 엑셀에서 **다른 이름으로 저장 → Excel 통합 문서(.xlsx)** 로 바꾼 뒤 올려 주세요.
- 양식에 ‘비고’ 칸이 없으면 비고는 화면에서 확인만 되고 엑셀에는 들어가지 않습니다.

## GitHub Pages로 공개하기

1. GitHub에서 새 저장소를 만들고 이 폴더의 파일을 모두 올립니다.
2. 저장소의 **Settings → Pages** 에서 *Source*를 `Deploy from a branch`, 브랜치를 `main` / `/ (root)` 로 정하고 저장합니다.
3. 1~2분 뒤 `https://<아이디>.github.io/<저장소이름>/` 에서 열립니다.

## 개인정보 주의

- 페이지는 파일을 어디에도 전송하지 않습니다. 양식 파일과 설정은 사용하는 브라우저의 저장소(localStorage)에만 남습니다.
- `.gitignore`가 엑셀 파일(`*.xlsx` 등)을 막아 두었습니다. **실제 학생 명단·출결 파일은 저장소에 올리지 마세요.** (`examples/`의 예시만 예외)
- 공용 PC에서 썼다면 브라우저의 사이트 데이터를 지워 저장된 양식을 없앨 수 있습니다.

## 구성

```
index.html      프로그램 전체 (HTML·CSS·JavaScript 한 파일)
examples/       연습용 가짜 양식·출결 파일
README.md       이 설명서
.gitignore      학생 엑셀 파일 업로드 방지
```
