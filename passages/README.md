# passages/ — 지문 넣는 곳

⚠️ 이 폴더의 지문 파일은 `.gitignore`로 GitHub에 올라가지 않습니다.
(모의고사 문제지는 "무단 전재 및 재배포 금지"입니다.)

## 파일 이름 규칙

| 문항 | 파일 이름 |
|---|---|
| 18번 | `18.txt` |
| 19번 | `19.txt` |
| … | … |
| 40번 | `40.txt` |
| 41~42번 (장문) | `41-42.txt` |
| 43~45번 (장문) | `43-45.txt` |
| 정답·해설 (선택) | `answers.txt` |

## 파일 내용 예시 (`31.txt`)

```
[31번] 다음 빈칸에 들어갈 말로 가장 적절한 것을 고르시오.

Few people may view the Star Trek universe through an economic lens, ...

① bias ② scarcity ③ pollution ④ diversity ⑤ efficiency

정답: ②
```

발문, 지문, 선지, (있으면) 정답까지 함께 넣으면 분석 품질이 가장 좋습니다.
문제지 PDF에서 복사해 붙여넣으면 됩니다.
